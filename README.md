
# AttendX-Test-Scripts

## Project Description
This repository contains sample test scripts for a
student attendance application called AttendX.

## Files
- `login_test.py`: Demonstrates basic login input validation.
- `attendance_marking_test.py`: Demonstrates basic attendance
  status validation.

## Requirements
- Python 3
- Git
- Visual Studio Code (optional)

## How to Run
Run the following commands from the repository folder:

```bash
python login_test.py
python attendance_marking_test.py
```

## Purpose
This repository demonstrates version control using Git and
GitHub, including staging, commits, pushing, pulling,
and viewing commit history.
